# 2D Platform Game

Welcome to the **2D Platform Game**! This project is a Unity-based 2D platformer with a pixel art theme.

## Features
- Classic 2D platformer mechanics.
- Pixel art graphics for a retro aesthetic.
- Engaging levels with challenges and obstacles.
- Smooth player controls and animations.

## Requirements
- Unity 2021.3 or later.
- Basic understanding of Unity for customization.

## Installation
1. Clone this repository to your local machine:
    ```bash
    git clone <repository-url>
    ```
2. Open the project in Unity.
3. Press the Play button to start the game.

## How to Play
- Use arrow keys or `A-D` to move the character.
- Jump over obstacles and avoid enemies using `SPACE`.
- Reach the end of the level to progress.
